# Loop Transformer Distillation

研究如何将 Qwen3-1.7B 的显式思维链蒸馏为循环隐式推理，并借鉴 diffusion LLM 的后训练方法改善推理成本与准确率之间的权衡。

## 当前状态

研究设计阶段，已整理文献、架构候选、训练路径和实验矩阵。尚未训练模型、复现实验或测量性能；本项目当前不包含可运行的模型实现。

## 核心问题

从 `Qwen/Qwen3-1.7B` 的现有权重出发，让原版模型使用显式 CoT 提供监督，训练通过循环 latent 工作区回答问题的学生。在明确的任务、硬件与服务负载下，检验学生是否能够降低实测推理成本，同时尽量保持教师准确率。

优先验证：在相同后训练计算预算下，答案奖励 RL 加上经过验证的跨深度自蒸馏，能否让 4 轮学生达到仅答案奖励 RL 的 8 轮学生的准确率，并保留分布外表现？

## 研究路径

1. 建立原版 Qwen3 的 no-thinking、短 CoT、长 CoT 基线。
2. 保留完整权重，验证循环 latent 工作区能否承担推理。
3. 比较固定预算答案 RL 与高预算到低预算自蒸馏。
4. 在固定预算能力确认后，训练预算选择或停止策略。
5. 最后单独检验共享层压缩的收益与损失。

第一个里程碑是可复现基线与最小循环学生。每个阶段的条件、对照和测量要求见研究提案。
